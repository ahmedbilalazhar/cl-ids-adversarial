Its claim that attack escalation was predeclared contradicts Phase 2. These findings do not imply the raw historical confusion counts are fabricated or that negative results are defects.

The newer single-attacker evidence supports **conditional, exploratory development-bank findings for the earlier 76-feature execution profile**. Independent audit found 417 unique full trajectories, including 240 primary trajectories, and 24 oracle suffixes. The 963 physical result files include 546 identical copies. These 76-feature outcomes and weights do not transfer to the adopted 74-feature profile. A new independent standard-library CSV pass reconstructed all 2,099,976 rows from the corrected archive; all row IDs, labels, timestamp/endpoint/protocol metadata matched, and all 74 transformed FP32 model inputs matched exactly. Binary64 decimal parser differences were observed but did not alter any FP32 input. The 60s sensitivity remains disjoint; 300s grouping joins 8,982 train/development components, so isolation is conditional on 120s. Both source archives have recorded archive/member integrity checks. The CPU extension uses the historically selected DR coefficients (lambda_y=1, lambda_z=.1), 12 rounds × 1 epoch, and fresh clean feasibility gates; it is a development-bank extension, not untouched confirmation. Provider authentication and true application-session identity remain uncertified.

Retaining supplied new-class rows is not evidence of improved learning. DR's maximum-dose immediate Hulk recall change is about -0.00064. Strong majority-attacker results cannot establish a stronger effect under the prescribed single-attacker threat.

Final-test scoring, external full-method efficacy and general deployment claims remain unsupported. Test payloads remain sealed. This audit does not promise independent-site generalization, privacy, novel-technique discovery, equivalence from non-significance, or a particular rubric score.
