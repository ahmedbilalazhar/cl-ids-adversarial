# Results

As of 2026-09-28, only a per-seed completion manifest with matching hashes
for R, summary, task NPZ, and task sidecar makes a seed validated. Historical
summary/R pairs remain executed-only, not counted by table/status/stat readers.
New manifest version 3 also hashes the runtime `src/*.py` tree, including
uncommitted source. Earlier version-2 diagnostic manifests are accepted by
the reader with `pre-code-hash` provenance and remain exploratory only.
The main aggregate CSVs are intentionally header-only until validated reruns.
`diagnostics/` holds three manifest-v2 checked exploratory seeds each for the CICIDS
duplicate-disjoint and T0-only scaler arms, not a 12-paired-seed paper result.
These arms use different task populations and leakage controls; their means
are not a causal estimate of the scaler or deduplication effect.
Legacy E4/E5 files and figures are in
`_archive/discovery_transductive_20260928/` with a checksum manifest. The
former clustering step used held-out flows and happened after classifier
training. No corrected paired E4/E5 result exists yet. New summaries
record FWT as null because the upper triangle was not measured.
Intermediate E4 seed-1 diagnostics were archived under
`_archive/discovery_pre_code_hash_20260928/` and
`_archive/discovery_pre_asr_null_20260928/`; a full nine-seed diagnostic was
archived under `_archive/discovery_pre_commit_asr_20260928/` after two source
files changed. The current
final-code diagnostic has nine version-3 seeds in `diagnostics/runs/`, three
per no-poison, anchor-poison, and direct-label-control arm. Its descriptive
summary is `diagnostics/e4_descriptive.json`; those nine were live against
source hash `94abb157…` at the time and are copy-preserved with a SHA-256
manifest in `_archive/discovery_prefedcontrols_20260928/` — later `src/`
changes altered the manifest-v3 fingerprint, so they no longer pass live
checks and must not be cited as current-provenance evidence. Seed-1 resource probes took
144.2 s / 862.3 MB, 145.6 s / 863.9 MB, and 124.7 s / 895.0 MB respectively
on the local CPU host (`CL_THREADS=2`). These are exploratory diagnostics,
not final paired inference.

## Regenerate

```bash
python -m src.run_experiment --rebuild-table
python scripts/stats_summary.py
python scripts/make_figures.py
```

Do not infer completion from a summary filename. `grid_status`,
`stats_summary`, and `--rebuild-table` validate completion manifests. Figures
must be regenerated only from validated tables; old figures are historical.
