# Results

## Layout

```
results/
  baseline_table.csv   master table (rebuilt via --rebuild-table)
  stats_summary.csv    aggregated stats
  wilcoxon.csv         Wilcoxon signed-rank comparisons
  e5_evasion*.json     discovery-evasion outputs
  e7_deployment.*      latency / peak-RSS
  figures/             generated by scripts/make_figures.py
  runs/                per-seed outputs (*_R_seed*.csv, *_summary_seed*.json)
  _archive/prefix0/    pre-fix runs (invalid — see README_ARCHIVED_PREFIX0.txt inside)
```

## Regenerate

```bash
python -m src.run_experiment --rebuild-table
python scripts/stats_summary.py
python scripts/make_figures.py
```

Per-seed `runs/*_R_seed*.csv` / `runs/*_summary_seed*.json` files are raw outputs of
`scripts/run_grid.py` + `scripts/run_groups.py` and are versioned for this project.
Readers (`grid_status`, `stats_summary`, `make_figures`, `--rebuild-table`) scan
`runs/` with fallback to the legacy flat layout.
