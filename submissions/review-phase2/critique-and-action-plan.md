Major revision and data/development gates are required. Single-reviewer audit. The paper-review launcher failed: Claude is absent. No panel verdicts are claimed. Both source versions are preserved. Y findings quote the pre-second-pass source; others quote the original. Actions distinguish fixes, clarifications and proposed amendments.


Critical

1. A1 — “nine tests on final anchor F1”. The targeted Hulk source appears in E2, whereas the observed E1 anchors are FTP-Patator and SSH-Patator. Anchor changes miss targeted damage. Proposed amendment: make E2 source recall damage and E3/E4 clean-matched targeted error primary; retain anchor scores as collateral endpoints and explain the shared-benign-region pathway.

2. A2 — “nominal shard-relative dose”. One client among five and a 10% shard ceiling produces approximately 2% global corruption only under balanced shards; skew and eligible-source saturation change this. Proposed amendment: use eligible-source fractions 0/10/30/50%, publish actual global corruption, and require a development attack-viability margin.

3. A3 — “its frozen pre-update checkpoint”. Hulk is unseen. Mislabeled source rows can have low benign loss, defeating selection, while legitimate Hulk is fully protected. Clarification: state conditional rejection and possible poison preservation; treat null or adverse security effects as valid outcomes.

4. A6 — “Reconstructed sessions are atomic”. The local MachineLearningCSV headers lack the identifiers needed to reconstruct sessions. Dataset defects confound artificial corruption. Proposed amendment: require an audited metadata sidecar, a bidirectional endpoint key and proposed 120-second gap; cite verified Engelen–Rimmer–Joosen evidence and quarantine disputed joins/labels.

5. A7 — “Require training/development/test support”. No threshold determines which classwise scores are credible. Current Heartbleed/SQL-injection/Infiltration train/test counts are 8/3, 15/6 and 25/11. Proposed amendment: require 50/50/50 rows after grouping for confirmatory scoring, exclude inadequate families without semantic pooling, and block lock if the source or anchors fail.

6. C1 — “Two-sided hypotheses ask”. The estimands lack formal definitions. Changing source endpoints also changes multiplicity. Proposed amendment: define symmetric paired-location nulls and alternatives, eighteen C1 contrasts and eleven C2 contrasts; mark all other analyses exploratory. Two families protect separate questions, without claiming experiment-wide error control.

7. C2 — “final paired seeds 1--11 and 42”. Seed resolution is unstated. Fix: report minimum exact two-sided p-values and Holm thresholds. Nine nonzero pairs can permit rejection in the eleven-test family; the amended eighteen-test family needs at least ten. These bounds are not power estimates.

8. X1 — “Table 5 reports CICIDS2017 accuracy/F1”. The verified Guo manuscript places 83.4/82.1% in Table 6; Table 5 describes applicability. Fix: correct both prose and comparison cells, retaining Table 12's verified 76.4% ablation. This is a factual error.

9. X2 — “Fit normalization only on the initial benign training pool”. This prospective instruction differs from the inspected artifact's offline T0+T1 scaler. Clarification: identify that existing behavior in Appendix B and require a rebuilt T0-only artifact before claims of future-label isolation. Existing numerical support does not certify the proposed split.

10. X3 — “within each scored capture day”. Global time cuts can leave late-occurring families without usable training/development support. Proposed amendment: group sessions within majority-label strata and allocate chronologically inside strata. Explicitly characterize the resulting ordered-family benchmark and its tradeoff with global chronology; qualify temporal claims.

11. A12 — “Save CPU/GPU model”. The design has hundreds of runs but no executable resource estimate. Proposed amendment: enumerate 81 development, 288 main, 72 external and 192 optional full runs, plus 24 continuations. Leave tier time unmeasured. Reduce scope to 321 planned runs if necessary, retaining twelve seeds and disclosing incomplete external coverage.

12. Y1 — “support-qualified class sets”. Stage indexing is missing, and acquisition uses learner-announced classes despite label corruption. Proposed amendment: score fixed evaluator-scheduled new families within stage-specific supported banks; absent learner outputs score zero and empty new-family banks block protocol lock.

13. Y2 — “Latest anchor, batch-gradient importance”. Inspection shows the federation loop replaces EWC anchors between rounds; violating the experience-level penalty. Fix/proposed amendment: mark implementation partial, freeze each stored anchor throughout the experience, then update admitted-data importance/anchor after final shared broadcast.

14. Y3 — “Six changed settings”. The keep-fraction sensitivity requires changing both DC and matched DM, so 144 optional runs undercounts the design. Fix: budget eight changed arm settings, producing 192 full runs; distinguish 633 enumerated full runs from 24 diagnostic continuations and unbudgeted calibration/reruns.

15. Y15 — “Its 70/30 counts”. Source inspection shows benign subsampling occurs before train/test splitting, changing evaluation priors. Proposed amendment: preserve natural development/test counts; sample only whole benign training sessions toward a disclosed 3,500-row target. Show legacy benign counts and prohibit claims that they represent natural test prevalence.
