Second-pass audit: sixteen additional weaknesses

Critical

Y1 — “support-qualified class sets”. Stage indexing is missing, and acquisition uses learner-announced classes despite label corruption. Proposed amendment: score fixed evaluator-scheduled new families within stage-specific supported banks, independent of head announcements; absent learner outputs score zero and empty new-family banks block protocol lock.
Y2 — “Latest anchor, batch-gradient importance”. Inspection shows the federation loop replaces EWC anchors between rounds; that differs from the stated experience-level penalty. Fix/proposed amendment: mark implementation partial, freeze each stored anchor throughout the experience, then update admitted-data importance/anchor after final shared broadcast.
Y3 — “Six changed settings”. The keep-fraction sensitivity requires changing both DC and matched DM, so 144 optional runs undercounts the design. Fix: budget eight changed arm settings, producing 192 full runs; distinguish 633 enumerated full runs from 24 diagnostic continuations and unbudgeted calibration/reruns.
Y15 — “Its 70/30 counts”. Source inspection shows benign subsampling occurs before train/test splitting, changing evaluation priors. Proposed amendment: preserve natural development/test counts; sample only whole benign training sessions toward a disclosed 3,500-row target. Show legacy benign counts and prohibit claims that they represent natural test prevalence.

Major

Y4 — “FIN/RST closes it”. A single FIN closes one TCP direction, making the proposed session boundary premature. Fix: require both-direction FINs or RST, preserve retransmissions and use upstream capture checksums; quarantine/re-extract crossing flows and verify packet-level metadata before grouping.
Y5 — “All admission filters are disabled in E1”. Disabling filters does not itself prove identical defense starting states. Clarification: clone/hash the entire E1 DER++ server and client-memory states across defense/dose arms; learner comparisons retain learner-specific starts. This removes an avoidable initialization/history confound.
Y6 — “recheck gates after tuning”. Pilot parameters, tuning order and the clean viability control are unspecified. Clarification: set pilot coefficients, select synchronization, tune only that budget among feasible configurations, then test tuned FT poison against its existing clean grid control. This makes the 81-run development budget executable.
Y7 — “Fix importance batches in evaluation mode”. The inspected nonshuffled loader can estimate importance from the beginning of a class-concatenated shard and miss later families. Proposed amendment: draw capped fixed-size batches from a dedicated uniform permutation, disable dropout and record batch/class coverage.
Y8 — “Holm acts within each named family”. Readers can mistake two separate .05 controls for a single experiment-wide .05 guarantee. Clarification: state the separate question families and lack of pooled control; severe symmetry failure leaves summaries exploratory without outcome-driven test switching.
Y9 — “withdraw in E3/E4”. Withdrawal introduces no clean Hulk observations, so recovery cannot be interpreted as successful source relearning. Clarification: define H as persistence without source reacquisition; keep claims conditional on this nonrecurring-family schedule.
Y10 — “matched capacity/exposure”. The oracle memory diagnostic leaves replacement and teacher history undefined. Proposed amendment: compare two cloned E2 states, replace poison from same-client nonresident honest admissions, refresh both teacher banks with the same poisoned checkpoint and match masks/occupancy. Budget 24 paired continuations; insufficient replacement support makes the diagnostic unavailable.
Y11 — “serialized updates”. Weight bytes or uplink payload alone cannot identify federation communication cost. Fix: measure uplink, downlink and control traffic separately from numeric parameter bytes; distinguish real serialization overhead from the float32 model-size formula.
Y12 — “a supported unpredicted class scores zero”. Zero F1 is valid, but precision is undefined when no examples are predicted; score ties can also make AP order-dependent. Fix: set zero-denominator precision to N/A and group equal detection scores into a single AP threshold.
Y13 — “uniformly among those with eligible E2 Hulk rows”. Fewer than ten eligible rows make the 10% floor an unchanged-label intervention. Proposed amendment: select uniformly among clients with at least ten source rows, preserving the same client across arms/doses and disclosing this conditioning.
Y14 — “nested ID-ranked subsets”. Raw-ID sorting can concentrate poison in a particular capture segment. Clarification: draw one seeded random eligible-ID permutation and use dose-dependent prefixes; IDs still break selection-loss ties, but no feature/time ordering chooses attack rows.
Y16 — “conditional training variability”. Seed intervals exclude uncertainty from fixed test captures, and sparse-flow intervals can mistake correlated flows for independent samples. Clarification: state the conditional estimand and require whole-session resampling for sparse-family intervals.
